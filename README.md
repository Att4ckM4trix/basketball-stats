# 🏀 מעקב סטטיסטיקות כדורסל

אפליקציית ווב למעקב אחרי הסטטיסטיקה האישית שלי במשחקי כדורסל. בניתי אותה כי אני משחקת, ורציתי לראות את ההתקדמות שלי לאורך העונה.

*A personal basketball stats tracker: game log, season averages, progress chart, and import from the Israel Basketball Association website. Vanilla JavaScript + a small Python server, no frameworks.*

**[לגרסה המקוונת](#)**: אפשר ללחוץ שם על "טעינת נתוני דוגמה" כדי לראות את האפליקציה עם נתונים.

## מה האפליקציה עושה

- **הזנת משחקים**: נקודות, ריבאונדים, אסיסטים, חטיפות, איבודים, זריקות מהשדה, שלשות ועונשין.
- **טבלה עם שורת ממוצעים**: אחוזי הקליעה העונתיים מחושבים מסך הקליעות חלקי סך הניסיונות, ולא כממוצע של אחוזים.
- **גרף התקדמות** של נקודות, ריבאונדים ואסיסטים לאורך העונה.
- **עריכה ומחיקה** של משחקים.
- **בדיקות היגיון**: למשל, אי אפשר לקלוע יותר זריקות ממה שנזרקו, או לזרוק יותר שלשות מכלל הזריקות מהשדה.
- **ייבוא מאתר איגוד הכדורסל**: מדביקים פעם אחת לינק לעמוד השחקנית, ובכל פעם שלוחצים "עדכון מהאתר" המשחקים החדשים ממלאים את הטופס. בודקים, מתקנים אם צריך, ושומרים.

## טכנולוגיות

| חלק | טכנולוגיה |
|---|---|
| ממשק | HTML, CSS, JavaScript (בלי ספריות, חוץ מ-Chart.js לגרף) |
| שרת | Python, ספרייה סטנדרטית בלבד (בלי התקנות) |
| שמירת נתונים | קובץ JSON במחשב (כשהשרת פועל), או `localStorage` בדפדפן |

## הפעלה במחשב

צריך [Python](https://www.python.org/downloads/) בגרסה 3.9 ומעלה.

```
python server.py
```

ב-Windows אפשר פשוט ללחוץ פעמיים על `start.bat`. האפליקציה נפתחת בכתובת `http://localhost:8000`.

## מבנה הפרויקט

| קובץ | תפקיד |
|---|---|
| `index.html` | מבנה הדף: טופס, גרף, טבלה |
| `style.css` | עיצוב |
| `app.js` | הלוגיקה: שמירה, חישובים, הצגה, ייבוא |
| `server.py` | שרת מקומי: מגיש את האפליקציה, שומר את המשחקים בקובץ, וקורא נתונים מאתר האיגוד |
| `demo-data.json` | משחקים לדוגמה (בדיוניים) לגרסה המקוונת |
| `start.bat` | הפעלה בלחיצה כפולה ב-Windows |

## החלטות שכדאי לדעת עליהן

- **שני מצבי שמירה.** האפליקציה בודקת אם יש שרת. אם יש, המשחקים נשמרים בקובץ `games.json`. אם אין (למשל ב-GitHub Pages), הם נשמרים בדפדפן. קובץ הנתונים האישי לא עולה ל-GitHub (`.gitignore`).
- **למה צריך שרת לייבוא?** דפדפנים חוסמים קריאה מאתר אחר (CORS), ולכן השרת הוא זה שמוריד את העמוד מאתר האיגוד.
- **התחשבות באתר המקור.** השרת ממתין 10 שניות בין בקשות, לפי `robots.txt` של האתר. הוא מוריד רק משחקים שעוד לא נשמרו, ומוכן לגשת רק לעמודי שחקניות באתר האיגוד.
- **אבטחה.** טקסט שמשתמשים מקלידים מוצג עם `textContent` ולא עם `innerHTML`. השרת מאזין רק למחשב המקומי (`127.0.0.1`).
